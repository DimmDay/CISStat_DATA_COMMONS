## Раздел II. Архитектурные принципы

1. ARC-001 — Everything is a Knowledge Object (EKO)
Любой артефакт платформы является объектом знаний.

2. ARC-002 — Metadata First
Сначала метаданные — потом данные.

3. ARC-003 — API First
Все функции доступны через API.

4. ARC-004 — Semantic by Design
Семантика проектируется изначально, а не добавляется позже.

5. ARC-005 — Knowledge Graph First
Все сущности связаны через корпоративный граф знаний.

6. ARC-006 — Repository as Enterprise Knowledge System
Репозиторий является системой управления знаниями.

7. ARC-007 — AI Native
Архитектура ориентирована на работу с AI-агентами, MCP, RAG и интеллектуальными сервисами.

8. ARC-008 — Human and Machine Readable
Любой артефакт должен быть одинаково пригоден для человека и машины.

9. ARC-009 — Everything Has a Persistent Identifier
Каждый объект имеет постоянный идентификатор и URI.

10. ARC-010 — Everything Is Traceable
Любое решение, требование и реализация должны быть прослеживаемы.

11. ARC-011 — Open Standards First
Используются международные открытые стандарты (SDMX, DDI, XBRL, RDF, OWL, Schema.org и др.).

12. ARC-012 — Infrastructure Agnostic & Headless by Design
Платформа CIS Data Commons проектируется как инфраструктурно-независимая (Infrastructure Agnostic), 
обеспечивающая возможность развертывания в любом совместимом вычислительном окружении без изменения архитектуры приложения.

13. ARC-013 — No Vendor Lock-in
Архитектура платформы не должна содержать критических зависимостей от конкретного поставщика программного обеспечения, облачной инфраструктуры или проприетарных сервисов, если существуют зрелые открытые стандарты или переносимые альтернативы.
Это означает:
- использование PostgreSQL вместо облачных СУБД с уникальными API;
- OpenSearch вместо сервисов поиска, доступных только у одного провайдера;
- Keycloak или совместимые OIDC-провайдеры вместо облачных IAM-сервисов;
- MinIO (S3-совместимое API) вместо зависимости от конкретного объектного хранилища;
- Kubernetes API как единый слой оркестрации независимо от дистрибутива.
